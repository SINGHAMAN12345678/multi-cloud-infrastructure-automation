# Multi-Cloud Infrastructure Automation

## Overview

This project demonstrates infrastructure automation across AWS and Microsoft Azure using Terraform.

## Technologies

- Terraform
- AWS
- Microsoft Azure
- Git
- GitHub Actions

## AWS Infrastructure

- Virtual Private Cloud (VPC)
- Subnet
- Configurable region and network ranges
- Resource tagging

## Azure Infrastructure

- Resource Group
- Virtual Network
- Subnet
- Configurable region and network ranges
- Resource tagging

## Security

- No cloud credentials stored in the repository.
- Terraform state files excluded from Git.
- Variable files excluded from Git.
- Cloud deployment requires authentication and approval.

## Project Structure

- terraform/aws
- terraform/azure
- .github/workflows
- docs/screenshots

## Deployment Status

Configuration is being developed and validated. Cloud deployment will be documented after successful testing.
